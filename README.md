# 沪居指南 · 微信小程序

基于《上海房价实时动态查询 APP — 系统设计架构》实现的微信原生小程序前端演示版。

## 已实现

- 找房首页：关键词、区域、总价、户型组合筛选，加载/错误/空状态
- 地图找房：房源价格点位、列表联动、用户定位
- 市场行情：全市指标、近 6 个月趋势、区域价格排行
- 房源详情：基础参数、历史价格、规则化优缺点、位置地图
- 收藏：本地持久化、收藏列表、价格提醒入口
- 我的：偏好、通知、隐私与数据来源说明

## 本地运行

1. 安装依赖：`npm install`
2. 执行检查：`npm run typecheck` 与 `npm test`
3. 打开微信开发者工具，导入本目录。
4. 当前 `appid` 为 `touristappid`，正式发布前替换为已申请的小程序 AppID。

## 一键提交到远端

完成 Git 初始化并配置 `origin` 后，双击根目录的 `一键提交到远端.cmd`。脚本会暂存全部修改、创建提交、推送当前分支，并核对本地与远端提交编号。

也可以在 PowerShell 中指定提交信息：

```powershell
.\scripts\push-all.ps1 -Message "feat: 完成房源筛选"
```

为防止误提交，脚本遇到疑似密钥文件、95 MB 以上文件、未配置远端或 detached HEAD 时会停止，不会执行强制推送、拉取、合并或历史改写。

## 接入真实服务

页面目前通过 `services/listing-service.ts` 读取本地模拟数据。后续可在该边界替换为 API 网关请求，并在应用启动后接入 WebSocket 价格推送。地图上线前需在小程序后台配置合法域名和位置权限；真实房源图片需通过已授权对象存储域名提供。

## 合规说明

本演示不抓取任何第三方平台，也不收集用户手机号。生产环境应优先使用官方或授权数据源，保留来源标注，并提供用户数据导出与删除能力。
